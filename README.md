# 🕊️ GraceAI (은혜의 기도) - 로컬 AI 기도 앱

사용자가 기도할 주제를 입력하면 **관련 성경구절 3개**와 **따뜻하고 은혜로운 기도문**을 자동으로 생성해주는 기독교 AI 기도 도우미 웹 애플리케이션입니다.

외부 클라우드 API 대신 사용자의 PC에서 직접 실행되는 **LM Studio 로컬 AI API (`http://127.0.0.1:1234`)**를 연결하여 완전한 개인정보 보호와 무료 오프라인 환경을 제공합니다.

---

## 🌟 주요 기능

1. **맞춤 성경구절 3개 추천**
   - 기도 제목과 마음에 가장 알맞은 성경 말씀 3구절을 엄선합니다.
   - 각 구절마다 정확한 위치([책 장:절]), 말씀 본문, 그리고 *묵상의 은혜* 가이드를 함께 제공합니다.
   - 개별 구절 복사 기능 지원.

2. **은혜로운 맞춤 기도문 생성**
   - 하나님을 향한 진솔한 고백, 말씀에 의지하는 간구, 감사의 찬양을 담은 기도문을 생성합니다.
   - 기도의 어조(위로와 평안, 간절한 간구, 감사와 찬양, 담대한 결단, 깊은 묵상) 및 기도 대상(나 자신, 가족/자녀, 친구, 공동체) 맞춤 설정 가능.

3. **실시간 스트리밍(SSE) 및 AI 묵상 과정 표시**
   - Gemma 4 12B 모델의 생성 과정을 실시간 타자 효과로 확인.
   - 추론/사고(Reasoning) 과정을 'AI 묵상 과정' 접이식 상자에서 투명하게 확인 가능.

4. **음성 낭독 (TTS)**
   - 생성된 기도문을 차분하고 경건한 음성으로 읽어주어 눈을 감고 기도에 집중할 수 있습니다.

5. **나의 기도함 (보관함)**
   - 은혜받은 기도문과 성경구절을 브라우저에 안전하게 저장하고 언제든 다시 묵상할 수 있습니다.

6. **은혜의 말씀 카드 제작 & 공유**
   - SNS 공유나 인쇄/PDF 저장을 위한 아름다운 기도 카드를 원클릭으로 생성합니다.

7. **LM Studio 원클릭 자동 연동**
   - `http://127.0.0.1:1234` 포트와 `gemma-4-12b-it` 모델을 실시간 자동 감지.
   - 상단 상태 뱃지로 연결 상태를 한눈에 파악.

## 🚀 실행 방법

### 방법 1. 깃허브 웹앱으로 바로 접속 (추천 / 설치 없이 즉시 실행)
별도의 서버나 프로그램 설치 없이 브라우저에서 즉시 실행할 수 있습니다.
* **웹앱 주소**: [https://songjs88.github.io/grace-prayer/](https://songjs88.github.io/grace-prayer/)
* **GitHub Pages 설정 방법**:
  1. 깃허브 저장소 상단 **Settings** -> 좌측 **Pages** 메뉴 클릭
  2. Build and deployment의 **Source**를 `Deploy from a branch`로 선택
  3. **Branch**를 `main`, 폴더를 `/(root)`로 지정 후 **Save** 클릭
  4. 약 1~2분 후 생성된 웹 주소로 스마트폰과 PC 어디서든 즉시 접속 가능합니다.
* **사용 팁**: 구글 Gemini 무료 API 키를 등록하시면 매일 1,500회 무료로 실시간 맞춤 기도가 작성되며, 키 없이도 즉시 고품질 샘플 기도문과 음성 낭독(TTS)을 체험하실 수 있습니다.

### 방법 2. 내 컴퓨터에서 직접 실행 (LM Studio 로컬 AI 연동)
1. **LM Studio** 실행 후 상단 **'Status: Running'** 확인 (`http://127.0.0.1:1234`)
2. `run_app.bat` 더블 클릭 또는 터미널에서 `python server.py` 실행
3. 웹 브라우저(`http://127.0.0.1:8000`) 접속

## 📁 프로젝트 구조

```
grace-prayer/
├── index.html       # ⭐ 깃허브 배포용 단일 완성형 웹앱 (GitHub Pages 엔트리)
├── style.css        # 글래스모피즘 & 성스러운 골드 빛 다크/양피지 테마
├── app.js           # 브라우저 직접 AI 연동 (Gemini 스트리밍 / Web Speech TTS)
├── manifest.json    # 모바일 PWA 홈화면 앱 설치 설정
├── icon-192.svg     # 고화질 벡터 골드 십자가 아이콘
├── server.py        # Python 백엔드 (LM Studio 프록시 & Edge-TTS 서버)
├── run_app.bat      # 윈도우 원클릭 로컬 실행 배치 파일
├── static/          # 백엔드 서버용 정적 리소스 모듈
└── README.md        # 안내 문서
```

## 💡 참고 사항 (LM Studio 팁)
- LM Studio 상단의 **Status**가 녹색(`Running`) 상태여야 합니다.
- 만약 포트 번호가 다르거나 다른 모델(예: Llama, Qwen 등)로 교체하고 싶으시면, 앱 우측 상단의 **설정(⚙️)** 버튼을 눌러 손쉽게 변경하실 수 있습니다.
